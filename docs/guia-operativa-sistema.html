Guia Operativa del Sistema SHP1

Resumen operativo y tecnico del bot, API y dashboard de SHP1 Pachuca.

Ubicacion del proyecto

/home/pc-ubuntu/servicios/bitacora-mtto

Procesos principales

  1. bitacora-bot: procesa WhatsApp.
  2. bitacora-api: expone dashboard y API.
pm2 status
pm2 logs bitacora-bot --nostream --lines 100
pm2 logs bitacora-api --nostream --lines 100

Grupos aceptados

  1. BITACORA-MTTO-SHP1 -> BITACORA
  2. Mantenimiento SHP1 -> MANTENIMIENTO_FALLAS
  3. MELI SVC PACHUCA - BATIA LIMPIEZA -> LIMPIEZA
  4. Asistencia SHP1 Pachuca -> MANTENIMIENTO_ASISTENCIA
  5. Ordenes preventivas semanales -> PREVENTIVO
  6. Centro Operativo SHP1 -> SUPERVISOR

Archivos principales

  1. index.js: router del bot.
  2. api.js: API y dashboard.
  3. db.js: conexion a PostgreSQL.
  4. handlers/: logica por grupo.
  5. services/: negocio y consultas.
  6. dashboard/: interfaz web.

Centro Operativo SHP1

Comandos activos:

  1. AYUDA
  2. REPORTE / RESUMEN
  3. LISTAR, ABIERTOS, CERRADOS, COMPLETADOS
  4. PREVENTIVOS, PREVENTIVOS CERRADOS
  5. ALERTAS, ALERTAS ASISTENCIA
  6. ASISTENCIA, ASISTENCIA HOY, EN TURNO
  7. GUIA PENDIENTE, GUIA PROYECTO

Asistencia y alertas

  1. Ingenieria usa Asistencia SHP1 Pachuca.
  2. Limpieza usa MELI SVC PACHUCA - BATIA LIMPIEZA.
  3. Las alertas usan 60 minutos de tolerancia.
  4. Las reglas de personal y descansos viven en services/limpieza-personal.js.

Dashboard

  1. Pestanas: Principal, Bitacora, Supervisor, Limpieza y Asistencia.
  2. Ya muestra alertas activas, asistencia y preventivos.
  3. Las tarjetas principales navegan a vistas detalladas.

Tablas importantes

  1. actividades_mtto
  2. actividades_limpieza
  3. evidencias_limpieza
  4. asistencia_limpieza_diaria
  5. asistencia_mantenimiento_eventos
  6. pendientes_supervisor
  7. preventivos_semanales
